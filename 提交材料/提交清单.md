## 二、硬性要求自查表

- [x] 全程无平台、厂商、个人水印，画面无遮挡标识（自托管开源 MindAR + Three.js）
- [x] 合集模式：单次扫描识别 **4 张**不同识别图（≥3 张要求）
- [x] 丢失追踪后可无缝切换任意一张识别图加载对应 AR 内容（maxTrack=1 多锚点自动切换）
- [x] 兼容网页端、安卓移动端、iOS 移动端，链接扫码即开，无需下载客户端
- [x] 多设备下模型加载、交互效果稳定一致（纯程序化几何，资源轻量）
- [x] AI 技术辅助创作：AI 提取非遗元素 / AI 生成视觉素材 / AI 辅助三维建模 / AI 优化色彩（详见《设计文档》与站内"作品说明"）
- [x] 系列化、系统化、综合性表达：四艺一体合集 + 统一品牌视觉 + 集齐彩蛋机制

## 三、评审快速体验指引（建议随作品提交）

1. 手机浏览器扫描【作品二维码】打开作品；
2. 若手边无打印海报：电脑打开同一链接 → 点「识别图预览」放大任意海报，手机点「开始 AR 体验」对准电脑屏幕即可识别；
3. 或点落地页下方四个"免相机直接预览"入口，无需相机直接查看四个 AR 场景；
4. 微信内打开如无法调起相机，请点右上角「···」→「在浏览器中打开」。
