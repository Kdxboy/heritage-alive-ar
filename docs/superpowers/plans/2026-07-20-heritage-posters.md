# 非遗 AR 系列海报生成 Implementation Plan

> **For agentic workers:** 本任务使用内置 image generation 工具逐张生成，并由当前会话逐张验收；无需代码实现或子代理。

**Goal:** 生成并保存四张满足 AR 识别与后期排版要求的同系列非遗海报 PNG 原图。

**Architecture:** 先用完整通用风格基底生成铜梁龙舞作为系列起点。后续每张以紧邻上一张为视觉参考，保留共同笔触、纹理密度、对比度和上下留白结构，同时更换题材与主色。

**Tech Stack:** 内置 image generation、PNG、PowerShell 文件检查、本地视觉核验。

## Global Constraints

- 1024×1536、2:3 竖版、PNG 原图直存。
- 顶部约 12% 和底部约 18% 不放主体，但保留细微背景纹理。
- 禁止任何文字、字母、数字、印章文样、水印、签名。
- 禁止大面积纯色平涂和规则重复纹样；细节必须适合 AR 特征追踪。
- 第二至第四张必须加入“与上一张保持同一插画风格和笔触，作为同一系列”。
