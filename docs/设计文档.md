# 《非遗活了》——活路儿 AR 系列互动海报 · 设计文档

> 参赛：中国好创意大赛 · 活路儿—地方非遗生成式人工智能专项赛
> 类别四：人工智能 + 数字文创类（AR 非遗数字交互文创作品）
> 日期：2026-07-20

## 一、作品概念

**作品名：《非遗活了》**（英文：Heritage, Alive!）

海报是静态的"展柜"，扫码打开相机对准海报，非遗当场"活"过来——
让非遗**不止走出展柜，更跳出纸面**。作品名即宣言，直接呼应活路儿
"让非遗被看见、被体验、被传播、被带回生活"的品牌理念。

四张系列海报 = 四个川渝国家级非遗项目，一个 AR 合集：

| # | 海报 | 非遗项目（地方性） | AR 内容 | 主题色 |
|---|------|-------------------|---------|--------|
| 1 | 《龙》 | 铜梁龙舞（重庆铜梁，国家级非遗） | 巨龙破纸腾空、盘旋舞动，点击迸发"火龙钢花"粒子 | 朱砂红 |
| 2 | 《画》 | 梁平木版年画（重庆梁平，国家级非遗） | 墨线版+套色版逐层拍印，演示"一画多版"套色工艺 | 藤黄 |
| 3 | 《绣》 | 蜀绣（川渝，国家级非遗） | 银针引线在空中一针一针绣出芙蓉鲤鱼纹样 | 松绿 |
| 4 | 《陶》 | 荣昌陶器（重庆荣昌，国家级非遗，中国四大名陶） | 陶坯在拉坯轮上旋转成型→施釉→窑变 | 赭陶 |

**集齐机制**：扫齐四艺解锁"四艺合卷"彩蛋（进度 x/4，localStorage 存档），
把四张海报从"并列"变成"系统"，对应赛题"系列化、系统化、综合性表达"。

## 二、赛题硬性要求 → 技术方案映射

| 赛题要求 | 方案 |
|----------|------|
| 无平台/厂商/个人水印 | 自托管开源 MindAR + Three.js，非商业 SaaS 平台，零水印 |
| 公开链接 + 二维码 + 识别图源文件 | GitHub Pages（HTTPS，AR 调用相机的前提）+ 本地 qrcode 库生成无水印二维码 + 提交 4 张识别图 PNG/SVG 源文件 |
| 合集模式，单次扫描识别 ≥3 张识别图 | 一个 targets.mind 编译 4 个图像目标，单页应用统一加载 |
| 丢失追踪后无缝切换任意识别图 | MindAR 多目标 targetIndex 监听，anchor lost/found 事件自动切换场景 |
| 网页端 / 安卓 / iOS 三端，扫码即开免下载 | 纯 WebAR（getUserMedia + WebGL），Safari/Chrome/微信外置浏览器均可 |
| 多设备加载、交互稳定一致 | 全程序化几何体（无大模型文件），资源总量控制在 ~5MB 内；像素比自适应 |
| AI 技术辅助创作 | 见"AI 工作流"节 |

## 三、系统架构

```
AR数字文创/
├── docs/                      # 设计文档、提交材料说明
├── posters/                   # 识别图源文件（SVG 源 + PNG 导出）
├── site/                      # 发布目录（整体推上 GitHub Pages）
│   ├── index.html             # 单页应用：落地页 + AR 视图
│   ├── targets/targets.mind   # 4 目标识别文件
│   ├── posters/*.png          # 识别图（站内预览用，评审可用第二块屏显示）
│   ├── js/
│   │   ├── app.js             # 落地页、权限、进度、场景路由
│   │   ├── scenes/dragon.js   # 铜梁龙场景（管状样条骨骼龙 + 钢花粒子）
│   │   ├── scenes/print.js    # 木版年画场景（分层版片拍印动画）
│   │   ├── scenes/embroidery.js # 蜀绣场景（针迹逐步绘制）
│   │   └── scenes/pottery.js  # 荣昌陶场景（车削几何成型 + 釉变）
│   └── vendor/                # three / mindar 本地化（不依赖外网 CDN）
├── tools/                     # 海报渲染、mind 编译、二维码生成、部署脚本
└── package.json
```

- **渲染**：Three.js 程序化建模（无外部 3D 模型文件），保证加载快、三端一致。
- **追踪**：MindAR image tracking，`maxTrack:1`，四目标注册，锚点事件驱动场景切换。
- **调试模式**：`?scene=dragon` 等参数免相机直渲场景，便于开发验证与评审快速预览。
- **降级**：不支持相机/WebGL 时落地页仍可浏览四艺知识卡片与识别图。

## 四、AI 工作流（生成式 AI 使用说明）

全流程由生成式人工智能（Anthropic Claude）辅助完成，对应赛题鼓励方向：

1. **AI 提取非遗传统元素**：从铜梁龙舞、梁平年画、蜀绣、荣昌陶的公开工艺
   特征中提取龙鳞、云纹、套色版式、针法肌理、器型轮廓等视觉基因；
2. **AI 重构创新纹样**：以矢量程序化方式原创重构纹样（非复制既有作品，
   版权清洁，契合大赛版权存证理念）；
3. **AI 生成视觉素材**：四张海报为 AI 生成的 SVG 矢量原创绘制；
4. **AI 辅助三维建模**：AR 场景全部为 AI 编写的程序化参数建模
   （样条管体龙身、车削陶坯、粒子针迹等）；
5. **AI 优化画质与色彩**：主题色板经无障碍对比度校验，三端渲染一致性调优。

## 五、视觉系统

- 品牌统一框架：延续活路儿"靛蓝 #2f5fa5 × 朱砂 #c2452f"品牌基因做版式框架
  （标题区、活路儿标识、"扫我，让非遗活过来"行动指引、系列编号）；
- 四色分主题：朱砂红（龙）/ 藤黄（画）/ 松绿（绣）/ 赭陶（陶）；
- 识别图适配：海报画面高细节、高对比、非对称构图，保证特征点密度与追踪稳定。

## 六、验证与风险

- 本地：调试模式逐场景截图检查；http 服务 + 无头浏览器验证加载与初始化。
- 真机：需要用户用手机扫码实测追踪（识别图可打印或屏显）。
- 风险：GitHub Pages 国内访问偶慢——保留一键重部署脚本，必要时可迁 Gitee/自有域名；
  微信内置浏览器对相机权限较严——落地页提示"如无法开启相机请用系统浏览器打开"。
